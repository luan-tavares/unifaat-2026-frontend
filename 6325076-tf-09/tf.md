## Descrição

Aplicação React com TypeScript desenvolvida para listar usuários e suas tarefas, consumindo a API do projeto da disciplina.

## Tecnologias utilizadas

- React
- Vite
- TypeScript
- Axios
- useState
- useEffect
- useRef
- Custom Hook useAxios

## Funcionalidades

- Listagem paginada de usuários.
- Visualização das tarefas por usuário.
- Filtro local de tarefas.
- Marcação de tarefas como concluídas.
- Tratamento de carregamento e erros.
- Cancelamento de requisições com AbortController.
- Atualização do título da página.
