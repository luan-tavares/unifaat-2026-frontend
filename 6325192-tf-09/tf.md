TF-09 - React: Referencias e Efeitos

Aplicativo React com TypeScript, Axios, useRef, useEffect e custom hook useAxios<T>.
Lista usuarios paginados da API do curso, lista tasks por usuario, filtro local,
refetch, atualizacao de task, indicador de salvamento, cancelamento com AbortController,
tratamento de erros e titulo dinamico da aba.

Para testar: iniciar a API em http://localhost:8080, entrar em app/, executar
npm install e npm run dev e acessar http://localhost:5173.
